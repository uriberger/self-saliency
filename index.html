Look Where You Say You’re Looking

Self-Grounded Attention for Visual Reasoning

TL;DR

We introduce Self-Saliency, a method for aligning where a model looks with what it talks about. Self-Saliency uses a grounding model to localize the objects mentioned in each reasoning step, and treats the resulting regions as supervision for the model's visual attention. On a broad suite of 25 visual reasoning benchmarks, it outperforms recent baselines.

Analysis

Training changes the text at the selected heads, and the attention across all of layer 22

We asked how training raises the reward: (1) by changing where visual attention goes, or (2) by changing the generated text.

Text. The model generates shorter completions, which refer to larger portions of the image.

Attention. We compute the reward on two selected heads (layer 22, heads 28 and 31). On the selected heads, the fraction of attention in referred regions stays the same after training. Across all the heads of layer 22, however, that fraction increases significantly.

Attention piles up on the image border

Across VLMs, visual attention concentrates on the geometric border of the image. Moreover, the most attended patch sits in a corner. In contrast, human annotators marked the center as the important region of the image.

Ablations

We run two ablations.

One explanation for Self-Saliency's gain is that it merely shifts attention toward the center of the image. To rule this out, we replace the grounding model's boxes with a fixed rectangle at the center, and train on that. We name this variant Center rect.

Another explanation is that response-specific grounding does not matter. Under this hypothesis, any boxes relevant to the image supply the same supervision. To rule this out, we give the grounding model the input question, and use the resulting boxes as supervision. We name this variant Question boxes.

Self-Saliency beats both ablations. Grounding the model's own response contributes meaningful feedback for training.
